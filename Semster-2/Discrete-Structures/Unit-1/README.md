# Unit 1 – Set Theory and Logic

Welcome to **Unit 1** of the Discrete Structures course.

This unit introduces the mathematical foundations required for the rest of the course. It covers sets, logic, predicates, quantifiers, and basic reasoning techniques that are widely used in mathematics and computer science.

---

## Learning Outcomes

After completing this unit, you should be able to:

- Understand set theory and set operations.
- Apply the Principle of Inclusion and Exclusion.
- Represent sets using computers.
- Explain fuzzy sets.
- Understand propositional logic.
- Construct truth tables.
- Identify logical equivalences.
- Work with predicates and quantifiers.
- Negate quantified statements correctly.

# Inclusion–Exclusion Principle

Two Sets

```text
n(A∪B)

=

n(A)+n(B)-n(A∩B)
```

Three Sets

```text
n(A∪B∪C)

=

n(A)+n(B)+n(C)

−n(A∩B)

−n(B∩C)

−n(A∩C)

+n(A∩B∩C)
```

# Truth Table Memory

NOT

```text

```

AND

Only TT is True.

OR

Only FF is False.

Implication

Only T→F is False.

Biconditional

Same = True

Different = False

# Unit 1: Past / Exam-Pattern Questions — Introduction to C++ and OOP

*Note: These are exam-style practice questions modeled on the CSIT 202 syllabus topics for Unit 1 (not scanned copies of actual past papers — if you have real past papers/question banks from your college, share them and I'll tailor these further to match the exact wording/pattern used).*

---

## Short Answer Questions (2-3 marks style)

1. Define OOP. List any four features of object-oriented programming.
2. Differentiate between C and C++. (List any 4-5 points)
3. What is meant by "C++ is a superset of C"?
4. Write the basic structure of a C++ program with a simple example.
5. What are `cin` and `cout`? Give an example of each.
6. Differentiate between `cin >>` and `getline()`.
7. What is the difference between `endl` and `"\n"`?
8. Define class and object with a suitable example.
9. What is encapsulation? How is it implemented in C++?
10. What is abstraction? Give a real-life example.
11. Differentiate between abstraction and encapsulation.
12. What is inheritance? Why is it used?
13. Define polymorphism. What are its two types in C++?
14. Differentiate between compile-time and run-time polymorphism.
15. Who developed C++ and when? What was it originally called?

## Long Answer Questions (5-10 marks style)

1. **Explain the evolution of C++ from C.** Discuss why object-oriented features were added on top of C, and how this addressed limitations of procedural programming.

2. **Discuss the key differences between C and C++** with a comparison table covering at least 6 points (paradigm, data security, function/operator overloading, inheritance, exception handling, I/O).

3. **Explain the structure of a C++ program** with a well-labeled example, describing each section (preprocessor directives, namespace, main function, function definitions).

4. **Explain the basic I/O operations in C++.** Write a program that takes a user's name and age as input and displays a greeting message using `cin` and `cout`.

5. **Explain the fundamental concepts of OOP** (class, object, encapsulation, abstraction, inheritance, polymorphism) with a C++ example for each.

6. **"Encapsulation and abstraction are related but different concepts."** Justify this statement with examples.

7. **Explain polymorphism in C++ with its types**, giving one example each for compile-time and run-time polymorphism (conceptual only, detailed programs come in Units 3 & 5).

8. **Why is `main()` required to return `int` rather than `void` in standard C++?** Explain with reference to program termination and OS interaction.

9. Explain how C++ improves upon C in terms of **data security and code reusability**, using OOP principles.

## Programming Questions

1. Write a C++ program to input two numbers and display their sum, difference, product, and quotient using `cin`/`cout`.

2. Write a C++ program to demonstrate the basic structure of a C++ program (include comments identifying each section: preprocessor directives, namespace, main function).

3. Write a simple C++ program with a class `Student` having a member function to display a welcome message, and create an object of it in `main()` to demonstrate the class-object relationship.

4. Write a C++ program to input a student's name, roll number, and marks, then display them in a formatted manner (demonstrates `cin`, `cout`, and basic variable use).

5. WAP (Write a Program) to demonstrate the use of `getline()` to read a full name with spaces, compared with `cin >>` which only reads a single word.

- C vs C++
- `cin` vs `cout`
- `endl` vs `"\n"`
- `struct` vs `class` (default access)
- Abstraction vs Encapsulation
- Compile-time vs Run-time polymorphism

## Quick Answer Bank (for fast revision before exam)
| Question | One-line Answer |
|---|---|
| Who created C++? | Bjarne Stroustrup (1979, Bell Labs), originally "C with Classes" |
| Is C++ a superset of C? | Yes |
| Default access in `class`? | private |

| Return type of `main()`? | `int` |
